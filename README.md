# XiaozhiCard 4G 网络电台

用于 M5Stack Xiaozhi Card 的网络广播固件，支持4G流量听电台、地区/节目类型分类、信号与充电状态显示，以及背键关机。

## 固件下载
在本仓库 **Releases** 中下载固件包。固件包包含全部镜像与 flash_args，请按其中的地址烧录，不能把 xiaozhi.bin 单独写到0x0。使用前核对设备为 ESP32-S3、8MB Flash、8MB PSRAM 的 Xiaozhi Card。

## 主要功能
- 2023条广播记录，支持地区与节目类型交叉筛选、页码直跳。
- 通过4G播放HLS、直接MP3/AAC直播；支持切台、暂停、音量调节。
- 显示信号、估算电量、充电/充满/外接供电及异常状态。
- 背键单击播放/暂停，双击或长按约2秒关机；关机后长按约2秒开机。
- 通电底座上电源操作只停止播放，离开通电底座后才执行关机。

## 构建
1. 使用 ESP-IDF **v6.0-dev-1489-g4e036983a75**，目标 esp32s3。
2. 源码包含本地组件与 dependencies.lock；无需递归拉取子模块。保留 .gitmodules 仅用于上游来源追踪。
3. 激活上述SDK环境后执行 idf.py build。
4. 连接正确设备后执行 idf.py -p PORT flash，或按发布包 flash_args 烧录。

音频组件为 esp_audio_codec 2.2.0；蜂窝网络组件为 esp-ml307 3.2.8，本仓库包含稳定性修补。相机组件包含与指定SDK兼容的补丁。上游的多板构建和消息转发工作流保存在 docs/upstream-workflows，仅作来源记录，不自动运行。

## 验证与限制
最新修复详见 [修复与验证说明](RADIO_FIXES_20261116.md)。固件已在目标设备完成烧录校验、4G联网和充电状态读取；播放列表回归检查在设备上通过。离底座开关机、低电量放空、故障注入、关机电流及长时间连续播放仍需进一步实测。

电量计报告容量与官方电池容量不符，带“~”的电量仅为电压估算，未修改电量计校准数据。电台源会失效，电脑网络验证不保证每张SIM均能播放，也不代表收尽中国所有广播。部分源带背景视频、流量较高；加密HLS及部分MAP/字节范围格式不支持。SIM必须允许访问公共电台地址，原配定向流量不一定适用。
